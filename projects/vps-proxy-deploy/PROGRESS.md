## 3. 目标与历史拓扑

用户最初为约 10 人配置代理，后来评估 35 人使用和另购中国优化线路。已部署的是自有 VPS 上的 **3x-ui + Xray + VLESS/TCP/REALITY**；这属于代理协议体系，不能把它与所有协议都可传输的三层 VPN 等同。

历史链路如下（各分支证据范围见后文）：

```text
Windows / Android 客户端
  └─ VLESS + TCP + REALITY ──> US_VPS
                                  ├─ 公司入站 TCP 2053
                                  └─ friends 入站 TCP 22537

NODE04（公司内网 Linux 主机）
  ├─ user705 的 SSH 动态转发：127.0.0.1:1080 ──> US_VPS:22
  ├─ root 系统服务 mihomo：配置目录 /etc/mihomo
  │    ├─ HTTP 12790 / SOCKS 12791 / redir 12792 / mixed 12793
  │    ├─ VPS-US 出站指向 127.0.0.1:1080
  │    └─ Meta TUN + 历史规则 + MATCH,VPS-US
  └─ Sub2API 容器：后台配置 HTTP 代理 <Docker网关>:12790
       （具体 socat 转发链及每个上游账号的实际请求路径尚未完整验收）

JP_VPS：曾安装与测试，之后用户再次申请退款；当前所有权未确认。
```

### 4.2 NODE04：SSH 隧道与持久化

**E3：用户终端输出已确认：**

## 6. 证据边界与需纠正的历史结论

以下**不得作为已经成立的项目结论**：

1. **慢连接 = SYN 重传率/丢包率**：不成立。未监听的日本 443 端口曾被用于测试，timeout/refused 更不能证明 GFW、QoS 或物理线路故障。
2. **BBR 使下载从某数值必然提升**：没有同源、同大小、同返回码的严格前后控制；下载还受远端发送方拥塞控制影响。
3. **TUN 覆盖所有用户/所有国外站点/所有容器**：未独立证明。环境变量、显式代理、旧规则和代理链均可能影响结果。
4. **Docker 8080 超时根因已经确定**：未做 route-get、抓包或回滚对照。观察到恢复不等于完整证实因果。
5. **客户端失败一定是新旧 Xray 不兼容**：未验证；所谓两种版本对比实际两次调用同一个 26.3.27。`spx` bug、缓存旧 SNI、链接多个 # 导致失败也没有证实。
6. **无连接日志 = 请求未到服务端**：不成立；日志未开启、抽样、输出级别、握手阶段、查看时间等都可能影响；只看 ESTABLISHED 快照也不能排除历史请求。
7. **REALITY 无 TLS 指纹/更换目标保证安全不封**：不成立。TLS1.3/H2 连通及启动无警告只是兼容性线索，不是抗识别或账号安全证明。
8. **flow 必须永远为空**：只是此次可工作的配置。Vision 可以另行正确部署，不能当协议禁令。
9. **固定人数必需多少流量或一个 IP 必然触发风控**：采购估算不是实测需求。1,000 GB ÷ 35 ≈ 28.57 GB/人/月只是算术；计费是否统计上下行、协议开销和实际行为仍需商家及用量确认。
10. **面板“速度限制”已配置、月额度自动刷新、35 人已部署**：都没有验收；需看具体版本功能及规则，不能只写流量值就当作带宽整形和月重置。
11. **HTTP 随机订阅链接“安全可控”或 CMFA 已成功导入**：不成立；见 4.6。
12. **日本 VPS 磁盘一定清空、物理存储阵列坏、模板一定标错、已退款或 IP 已归别人**：现有证据不支持定论。
13. **Proton/邮箱扫描、机房 IP、时区导致 Claude 登录失败**：均未确定。最初把 Proton 误判为 QQ 邮箱的解释应撤回；没有注册风控权重证据。
14. **Team/Enterprise 不封号、不需个人验证；代注册/换 IP 一定可用**：无证据，不能成为操作建议。
15. **把浏览器时区语言改成美式便与 VPS“真实时区”完全一致**：IP 地理数据库曾在 San Jose/Buffalo 间冲突；VPS 系统日期也曾为 UTC。Windows 改美东时区及单独英文 Edge 验证输出有证据，但不能证明消除风控。

KYC 的时间线讨论主要取自当时二手新闻，官方帮助正文未成功完整读取；本项目不把这些讨论固化成当前官方政策。后续如需使用服务，应重新核对官方可用地区、账户条款和身份验证要求。
